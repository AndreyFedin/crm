# Bitrix24: форматирование UF_NUM

Production-реализация для пользовательского поля `UF_NUM` типа `double`.

## Формат

Исходное значение:

```text
1234567.89
```

В просмотре и редактировании:

```text
1 234 567.89
```

На сервер / в CRM отправляется:

```text
1234567.89
```

## Возможности

- визуальное разделение групп разрядов пробелами;
- десятичный разделитель в UI — точка;
- десятичный разделитель в сохраняемом значении — точка;
- пробелы не передаются в реальное значение поля;
- точность берётся из `SETTINGS['PRECISION']`;
- при `PRECISION = 2` после потери фокуса значение нормализуется, например в `1 234 567.89`;
- кастомизация применяется только к `UF_NUM`;
- остальные поля типа `double` работают через штатный шаблон Bitrix;
- множественное `UF_NUM` использует штатный шаблон;
- при вставке числа с запятой оно нормализуется к точке.

## Установка

Скопировать каталог `local` из архива в корень сайта:

```text
<DOCUMENT_ROOT>/local
```

После установки очистить кеш Bitrix.

## JS extension

Расширение:

```text
company.uf-number
```

Готовый bundle уже находится в:

```text
/local/js/company/uf-number/dist/uf-number.bundle.js
```

Сборка на production не требуется.

Для пересборки:

```bash
cd /home/bitrix/www/local/js/company/uf-number
bitrix build
```

## Если код поля отличается

В шаблонах заменить проверку `UF_NUM` на требуемый код поля.
