# Bitrix24: форматирование UF_NUM

Готовая production-реализация для пользовательского поля `UF_NUM` типа `double`.

## Что делает

- `1234567.89` отображается как `1 234 567,89`;
- в режиме редактирования разряды форматируются сразу при вводе;
- дробный разделитель в UI — запятая;
- реальное значение, отправляемое в CRM, остаётся каноническим: `1234567.89`;
- точность берётся из `SETTINGS['PRECISION']`;
- логика применяется только к полю `UF_NUM`;
- остальные поля типа `double` используют штатные шаблоны Bitrix;
- множественное `UF_NUM` намеренно переключается на штатный шаблон.

## Установка

Скопировать содержимое каталога `local` из архива в `<DOCUMENT_ROOT>/local`.

После установки очистить кеш Bitrix.

## JS extension

Расширение:
`company.uf-number`

В архив уже включён готовый:
`/local/js/company/uf-number/dist/uf-number.bundle.js`

Поэтому сборка на production не обязательна.

Если требуется пересобрать из `src`:

```bash
cd /home/bitrix/www/local/js/company/uf-number
bitrix build
```

## Поле

Кастомизация включается только если:

```php
FIELD_NAME === 'UF_NUM'
```

Если код поля другой — заменить `UF_NUM` в:

- `main.view/.default.php`
- `main.edit/.default.php`

## Формат

В интерфейсе:

```text
1 234 567,89
```

На сервер отправляется:

```text
1234567.89
```
