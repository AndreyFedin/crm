# Битрикс24: отдельный тип пользовательского поля «Число с разделением разрядов»

Добавляется отдельный пользовательский тип:

    USER_TYPE_ID = formatted_number

Название в интерфейсе:

    Число с разделением разрядов

Стандартный тип `double` не переопределяется.

## Формат при PRECISION = 2

Хранение:
    1234567.89

Просмотр:
    1 234 567.89

Редактирование:
    1 234 567.89

В POST/CRM:
    1234567.89

## Установка

1. Скопировать каталог `local` из архива в корень коробочного Битрикс24.
2. Открыть «Настройки → Настройки продукта → Модули».
3. Установить модуль «Форматированное числовое поле».
4. Очистить кеш Битрикс.
5. Создать НОВОЕ пользовательское поле.
6. Выбрать тип «Число с разделением разрядов».
7. Указать точность, например 2.

## Важно

Тип существующего `UF_NUM` напрямую в БД не меняйте.
Если нужно заменить его новым полем, создайте новое UF и перенесите значения.

## Архитектура

Класс:
    /local/modules/company.formattednumber/lib/userfield/formattednumbertype.php

После установки JS-extension:
    /local/js/company/formatted-number/

Новый тип наследует штатный `Bitrix\Main\UserField\Types\DoubleType`.
Поэтому сохраняются PRECISION, MIN_VALUE, MAX_VALUE, DEFAULT_VALUE,
числовая валидация, физический тип колонки и нормализация перед сохранением.

Множественность в этой реализации отключена.
